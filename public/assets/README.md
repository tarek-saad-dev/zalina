# Image Assets

Place the following images in this `/public/assets/` folder:

## Required Images for Hero Section

1. **zalina-hero-bg.png** - Main hero background image
   - Recommended: High-resolution nighttime Arabian resort/palace image
   - Aspect ratio: 16:9 or wider
   - Minimum: 1920x1080px
   - Should show: Palm trees, Arabian architecture, warm golden lighting at night

2. **zalina-logo-full.png** - Logo for navbar
   - Recommended: Square logo (PNG with transparency preferred)
   - Size: At least 120x120px
   - This appears in the top navigation bar

3. **zalina-watermark.png** - Large decorative watermark
   - Recommended: Large decorative logo/illustration
   - Size: At least 800x800px
   - Should have transparency or work well as overlay
   - This appears as a subtle background element behind the building

## Optional Images

You can replace these with your actual images once available.

For now, the site will work without them (Next.js Image component handles missing images gracefully in development).

## Image Optimization

- Use `.png` or `.webp` formats for best quality
- Compress images for web use
- Use next-gen formats (WebP) when possible
